# PasarBengkulu - Marketplace Tradisional Bengkulu

Marketplace untuk UMKM Bengkulu. Tugas Web Programming.
Universitas Muhammadiyah Bengkulu - 2026

## Link
- Demo Online: https://pasarbengkulu.infinityfreeapp.com
- Demo Lokal: http://localhost/pasarbengkulu
- GitHub: https://github.com/divkadiv22-png/pasarbengkulu

## Fitur
1. Halaman depan dengan search produk
2. Detail produk
3. Keranjang belanja (session)
4. Checkout & simpan ke pesanan
5. Riwayat pesanan
6. CRUD produk untuk penjual
7. Dashboard penjual dengan total omset

## Teknologi
PHP Native, MySQL, Bootstrap 5, XAMPP

## Cara Install
1. Clone ke C:/xampp/htdocs/pasarbengkulu
2. Buat database `pasarbengkulu` di phpMyAdmin
3. Import `database.sql`
4. Buka http://localhost/pasarbengkulu
